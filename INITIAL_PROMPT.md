# Project
Enigma is a tool for charing files and folders in realtime between machines.

## Issue
the issue now days is that agentic work is burning to much resources, which makes you work on multiple machines at once
in order to share the resources usage.
if on machine#1 you work on the Claude.md file to do a better job for your project, the other machines will not be 
aware of that change unless you write it in multiple machines/share changes on demand -> results in machine#1 does a better job
then machine#2.

## Purpose
push over the gap of working on multiple machines due to resource lacking - the real issue with agentic work.

## What it is not
this is not Git replacement. never meant to share full projects or code base. 

## Developer whishes
i would like a service that runs in the background that sync between machines. i will choose the files/dirs and their destinations. 

the machine will have to have ssh access between them (unless there is a better way).
